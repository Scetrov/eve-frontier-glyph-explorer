01 / PRIMARY DATA

Original research

CANONICAL GLYPH CORPUS

George Peralta / QZRChedders

Creator and maintainer of ArchiveInvest: source-video collection, manual 9×9 tagging, canonical glyph dictionary, transcript archive, clustering work, and the browser-based grid tagging tool. The local repository history identifies QZRChedders as its author.

github.com/QZRChedders/ArchiveInvest

UNIVERSE DATASETS

Scetrov

Creator and maintainer of the public EVE Frontier datasets repository used as a supporting reference for star-system, celestial-object, and map-oriented hypotheses. No claim is made that those datasets presently decode the glyphs.

github.com/Scetrov/evefrontier_datasets

ADDITIONAL OBSERVATIONS

Local Cycle 4–6 captures

Eight supplied recordings were sampled with FFmpeg at the six-frame glyph cadence. Their 181 readings remain marked provisional so they can be distinguished from ArchiveInvest's manually tagged source data.

03 / METHODS

Tools and inspiration

VIDEO EXTRACTION

FFmpeg

Used to decode videos and extract settled frames at the observed glyph cadence.

ffmpeg.org

DECODING RECIPES

CyberChef / GCHQ

Standard binary, byte-alignment, Bacon, ITA2, and transform-oriented tests were inspired by CyberChef workflows. CyberChef code is not bundled in this site.

gchq.github.io/CyberChef

INTERFACE TYPE

Disket Mono / Rostype

Disket is a grid-based display monospaced typeface designed by Mariano Diez, with its Cyrillic set by Denis Ignatov. This explorer uses its regular and bold weights.

View the typeface at Rostype
